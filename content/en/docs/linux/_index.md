On Linux, SPL Sense runs without its own window as a web server in the background. You operate it in the browser, on
the device itself or from another computer, tablet or phone in the same network. This suits permanent measuring
stations, for example a Raspberry Pi in a club or in a rack.

You are basically free in your choice of hardware; an ARM architecture (32 or 64 bit) is required. This guide describes
the Raspberry Pi.

1. [Hardware and operating system]({{< relref "hardware" >}}): what you need and how to prepare the Raspberry Pi
2. [Installation]({{< relref "installation" >}}): install SPL Sense and set it up as a service
3. [Update]({{< relref "update" >}})
4. [Operation]({{< relref "operation" >}}): access, kiosk display and unattended operation

If you are familiar with Linux, SSH and the command line, you can go straight to the
[installation]({{< relref "installation" >}}).

Except for calibrating the sensor, SPL Sense on Linux can do everything it can do on Windows and macOS.
