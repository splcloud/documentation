Here you will find everything about **SPL Sense** (the measurement software on your computer) and **SPL Cloud** (the
online archive and team collaboration). This documentation describes version 2.0.

## Where do you want to start?

| You want to … | Read … |
|---|---|
| measure for the first time | [Quick start]({{< relref "quick-start" >}}): create a measurement, set the offset, measure, archive in the cloud, PDF report |
| know SPL Sense in detail: value profiles, live screen, leveler, calibration, autonomous mode | [SPL Sense]({{< relref "spl-sense" >}}) |
| run SPL Sense on a Raspberry Pi as a fixed measuring station | [SPL Sense for Linux]({{< relref "linux" >}}) |
| work with several measuring points, in a team or with authorities | [SPL Cloud]({{< relref "spl-cloud" >}}) |
| alarms, remote control, shareable links, reports with deviations and pictures | [SPL Cloud Pro]({{< relref "spl-cloud-pro" >}}) |
| integrate SPL Sense into your own systems | [For developers]({{< relref "developers" >}}) |
| look up terms such as LAeq, A/C/Z or offset | [Basics]({{< relref "basics" >}}) |

## Help in the app

In SPL Sense and SPL Cloud, the **Help** button (question mark at the top right) opens this documentation.
<kbd>Ctrl</kbd>+<kbd>K</kbd> (Mac: <kbd>⌘</kbd>+<kbd>K</kbd>) searches measurements and settings in both apps.
