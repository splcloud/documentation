Die SPL Cloud unter [spl.cloud](https://spl.cloud) archiviert die Messungen von SPL Sense und macht sie im Browser
verfügbar, von überall und für alle, denen du Zugriff gibst. Sie läuft parallel zu SPL Sense: Gemessen wird immer
lokal, die Cloud erhält die Daten laufend, sobald Internet da ist.

Alles in diesem Kapitel ist kostenlos, ausser wo Pro vermerkt ist. Zusatzfunktionen wie Tagesberichte, Alarme,
Fernsteuerung oder teilbare Links gibt es pro Messung mit [SPL Cloud Pro]({{< relref "/docs/spl-cloud-pro" >}}).

Dieses Kapitel richtet sich an Fachleute. Für den Einstieg reicht der [Schnellstart]({{< relref "/docs/schnellstart" >}}).
