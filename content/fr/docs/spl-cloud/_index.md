SPL Cloud, sur [spl.cloud](https://spl.cloud), archive les mesures de SPL Sense et les rend disponibles dans le
navigateur, de partout et pour toutes les personnes à qui vous donnez accès. Il fonctionne en parallèle de SPL Sense :
la mesure se fait toujours localement, le cloud reçoit les données en continu dès qu'Internet est disponible.

Tout ce chapitre est gratuit, sauf mention de Pro. Les fonctions supplémentaires comme les rapports journaliers, les
alarmes, la commande à distance ou les liens partageables sont disponibles par mesure avec
[SPL Cloud Pro]({{< relref "/docs/spl-cloud-pro" >}}).

Ce chapitre s'adresse aux professionnels. Pour débuter, le [démarrage rapide]({{< relref "/docs/quick-start" >}})
suffit.
