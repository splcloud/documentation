Avec un lien partagé, toute personne qui a le lien voit une mesure ou tout un événement, sans compte SPL Cloud. C'est
typique pour les organisateurs, les exploitants et les autorités, ou comme code QR dans le bureau de production d'un
festival.

Pour les personnes ayant un compte, il existe l'[accès en lecture]({{< relref "/docs/spl-cloud/read-access" >}})
gratuit.

## Condition préalable

- Lien vers une **mesure** : la mesure a besoin de Pro.
- Lien vers un **événement** : l'événement a besoin de Pro (**Activer Pro pour le job**). Pro sur des mesures
  individuelles de l'événement ne suffit pas.

## Créer un lien

1. Menu **Mesures** ou **Événement** › **Gérer l'accès en lecture**.
2. Sous **Lire les liens d'accès** : **Ajouter un lien d'accès**.
3. **Sélectionner le champ d'application** : cette mesure ou tout l'événement.
4. **Expiration** : la date à partir de laquelle le lien ne fonctionne plus. Laissez vide s'il ne doit pas expirer. Nous
   recommandons une date environ dix jours après l'événement.
5. **Sauvegarder**.

Vous voyez ensuite le lien et le code QR. **Copier** copie le lien, par exemple pour un e-mail. Vous pouvez imprimer le
code QR.

{{% alert title="Attention" color="warning" %}}
Toute personne qui a le lien voit les données de mesure. Ne le transmettez que là où c'est voulu.
{{% /alert %}}

## Ce que voient les destinataires

Les destinataires ouvrent le lien dans le navigateur et voient la mesure ou l'événement avec toutes les données, les
jours, les événements et les photos. Ils peuvent télécharger les rapports journaliers et les exports CSV. Ils ne peuvent
rien modifier et ne voient que ce que le lien partage.

## Révoquer un lien

**Gérer l'accès en lecture** liste tous les liens avec leur expiration. **Retirer** invalide un lien immédiatement.

## Quand Pro prend fin

Si Pro est désactivé ou si le paiement échoue, les liens ne fonctionnent plus. Les destinataires voient alors
**Ce lien partagé n'est actuellement pas disponible.** Les liens restent enregistrés et fonctionnent à nouveau dès que Pro
est réactivé.
