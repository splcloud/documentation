Tu trouveras ici tout sur **SPL Sense** (le logiciel de mesure sur ton ordinateur) et **SPL Cloud** (l'archive en
ligne et le travail en équipe). Cette documentation décrit la version 2.0.

## Par où commencer ?

| Tu veux … | Lis … |
|---|---|
| mesurer pour la première fois | [Démarrage rapide]({{< relref "quick-start" >}}) : créer une mesure, régler l'offset, mesurer, archiver dans le cloud, rapport PDF |
| connaître SPL Sense en détail : profils de valeurs, vue live, leveler, calibration, mode autonome | [SPL Sense]({{< relref "spl-sense" >}}) |
| utiliser SPL Sense sur un Raspberry Pi comme station de mesure fixe | [SPL Sense pour Linux]({{< relref "linux" >}}) |
| travailler avec plusieurs points de mesure, en équipe ou avec les autorités | [SPL Cloud]({{< relref "spl-cloud" >}}) |
| alarmes, commande à distance, liens partageables, rapports avec dépassements et photos | [SPL Cloud Pro]({{< relref "spl-cloud-pro" >}}) |
| intégrer SPL Sense dans tes propres systèmes | [Pour les développeurs]({{< relref "developers" >}}) |
| trouver la signification de LAeq, A/C/Z ou offset | [Notions de base]({{< relref "basics" >}}) |

## Aide dans l'application

Dans SPL Sense et SPL Cloud, le bouton **Aide** (point d'interrogation en haut à droite) ouvre cette documentation.
<kbd>Ctrl</kbd>+<kbd>K</kbd> (Mac : <kbd>⌘</kbd>+<kbd>K</kbd>) permet de rechercher des mesures et des paramètres dans
les deux applications.
